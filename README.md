# EchoFlow 可信 AI 内容运营平台

EchoFlow 是面向中国本地企业实习场景的 AI 辅助内容运营原型。它把方案知识、营销活动、品牌规则、AI 创作、人工审核、内容资产与运营分析连接为一条可追溯的工作流。

> 数据边界：仓库中的方案、内容、审核和评测记录均为虚构演示数据，不包含真实客户、政府合作、采购系统或企业内部数据。

## 核心能力

- 运营总览：活动进展、审核队列、质量、合规与复用指标。
- 方案知识库：结构化管理业务问题、能力、价值、技术亮点和来源。
- 活动中心：按营销活动组织目标、渠道、负责人和内容资产。
- AI 创作：基于方案、受众、策略、品牌与渠道生成结构化初稿。
- 审核中心：编辑、退回、批准与版本记录，默认强制人工审核。
- 内容资产库：按活动、渠道和状态检索并导出可复用资产。
- 品牌治理：统一品牌语气、推荐术语、禁用表达和必要声明。
- 数据洞察：从底层记录实时计算质量、合规、效率和复用表现。

## 工作流

`可信方案知识 → 营销活动 → 信息策略 → AI 初稿 → 人工审核 → 内容资产 → 跨渠道复用 → 数据分析`

API 模式通过服务端 OpenAI Responses API 生成内容，并使用严格 JSON Schema 约束返回结构；未配置密钥或接口不可用时会安全回退到确定性的演示模式。密钥不会发送到浏览器。

## 技术架构

```text
app/page.tsx                 中文产品界面与交互工作流
app/lib/echoflow.ts          领域模型、演示数据、治理评分、指标和导出
app/api/generate/route.ts    带输入校验和安全回退的 AI 生成接口
app/api/state/route.ts       D1 工作区持久化与乐观并发控制
db/schema.ts                 Drizzle / Cloudflare D1 数据结构
tests/echoflow.test.mjs      领域逻辑与安全边界测试
```

项目保留原有 Next.js、React、vinext、Cloudflare Workers、D1 和 Drizzle 架构。工作区以版本化 JSON 记录持久化到 `workspace_state`，当前数据版本为 `schema_version: 4`。

## 本地运行

环境要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

质量验证：

```bash
npm run lint
npx tsc --noEmit
npm test
```

## 可选 API 模式

在托管环境中配置以下服务端变量，然后在“品牌与治理”中选择 API 模式：

```text
OPENAI_API_KEY=<服务端密钥>
OPENAI_MODEL=gpt-5.6-luna
```

## 当前限制

- 这是单工作区原型，尚未实现企业身份、租户隔离和细粒度权限。
- 生成内容必须经过业务与合规人员核验后才能对外使用。
- 未实现 CRM、自动发布、政府数据库或真实采购系统集成。
- 演示评测用于验证计算与交互，不代表真实员工生产率或商业效果。
